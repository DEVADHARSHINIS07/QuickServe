QuickServe Smart Canteen

QuickServe is a React + TypeScript + Express full-stack app. TypeScript files (/src/main.tsx) must be compiled by Vite and cannot be served directly with VS Code Live Server (port 5500).

To start QuickServe properly:
1. Open VS Code terminal: Ctrl + `
2. Run: npm run dev
3. Open: http://localhost:5000

Running npm run dev starts the backend API and compiles all TypeScript files with correct JavaScript MIME types.
